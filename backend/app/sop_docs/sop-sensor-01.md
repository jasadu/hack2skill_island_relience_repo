# Demo SOP — not an approved field procedure.
## sop-sensor-01 Sensor verification
### sop-sensor-01#1 Stale or missing readings
If the tank level sensor is stale or missing, do not trust any reserve forecast. Report the forecast as unavailable.
### sop-sensor-01#2 Verify manually
Ask the facilities coordinator to read the tank gauge manually and compare it with the last good sensor value.
